# B 题问题一完整解答设计

## 目标

独立完成 B 题问题一，给出从多个检测点及示向度计算多边形定位区域直径的可执行算法，并回答以该直径为直径的圆能否覆盖定位区域。最终交付 Markdown 解答、Python 实现和自动化测试。

## 建模与算法

每次测向的真实方向位于读数两侧各 1° 的扇形内。将扇形的两条边界分别写成半平面不等式；所有检测点对应半平面的交集即为定位区域。程序枚举边界直线的两两交点，保留满足全部不等式的点，再用单调链算法按逆时针顺序生成凸多边形。

凸多边形的直径等于其顶点间最大距离。正文采用旋转卡壳算法求解，并保留两两枚举作为小规模校验方法。若有效顶点数少于 3，程序明确报告空集、退化或无法形成有界多边形，而不输出误导性的正常结果。

## 圆覆盖结论

取直径端点的中点为圆心、定位区域直径的一半为半径。该圆不一定覆盖整个定位区域；等边三角形即可作为直观反例。对具体定位区域，只需检查全部多边形顶点到圆心的距离是否不超过半径。程序同时实现该判定。
