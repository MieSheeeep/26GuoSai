# B 题 LaTeX 论文模板设计

## 目标

为“无线电干扰源的快速自动定位与清除”建立一套可直接填写、可用 XeLaTeX 编译的中文数学建模论文模板。模板结合四个问题预置写作结构、常用公式、算法、表格和代码占位内容，不虚构实验数据或结论。

## 工程结构

项目根目录新增 `latex/`，其中：

- `main.tex`：唯一编译入口，设置论文元信息并装配各章。
- `config/`：集中保存宏包、版式和自定义命令，正文文件不重复配置格式。
- `chapters/摘要/`、`chapters/问题重述/`、`chapters/问题分析/`、`chapters/模型假设/`、`chapters/符号说明/`：论文公共前置部分。
- `chapters/问题一/` 至 `chapters/问题四/`：每个问题独立成目录，目录内仅保留一个 `main.tex`，问题分析、模型建立、算法设计和结果分析均写入该文件。
- `chapters/模型评价与推广/`、`chapters/参考文献/`、`chapters/附录/`：论文公共后置部分。
- `figures/`、`tables/`、`code/`：分别保存图片、独立表格和支撑程序。
- `README.md`：给出编译命令、目录说明和填写顺序。

正文由 `main.tex` 使用 `\input` 按固定次序装配。所有路径以 `latex/` 为基准，目录名保留中文以直观对应论文大标题。

## 版式与编译

- 默认编译引擎为 XeLaTeX，纸张为 A4。
- 使用 `ctexart` 提供中文排版，正文采用常见的宋体风格，标题使用黑体风格。
- 设置页边距、行距、段首缩进、页码、标题层级、图表标题、公式编号和超链接。
- 封面不写学校、队员姓名等身份信息，仅保留论文题目、题号和参赛队号占位符。
- 摘要页预置摘要、关键词，并避免把目录强制作为正文内容；目录由用户在需要时通过开关启用。
- 依赖尽量选择常见 TeX Live/MiKTeX 宏包，避免冷门宏包降低可移植性。

## B 题专属内容

### 问题一

预置示向度误差扇形约束、半平面交、圆域约束、凸多边形顶点求取、旋转卡壳/顶点对枚举求直径，以及“以直径为直径的圆是否覆盖定位区域”的判定框架。提供算法伪代码、示意图占位和数值结果表。

### 问题二

预置第二检测点选址的目标与约束，包括交会角、基线长度、有效接收半径、目标圆域和移动代价。提供候选区域定义、综合评分函数、参数敏感性表和候选区域示意图占位。

### 问题三

预置全向干扰源搜索、频道扫描、二次测向、定位、接近与清除的状态流程；明确移动、切换频道、检测、光学定位和清除的时间模型。提供演练统计表，以及题目要求的三次正式测试结果表，数据单元保持为空白占位。

### 问题四

在问题三框架上增加定向干扰源的可见半平面、漏检风险、多方向复测和搜索路径补偿。提供全向/定向源统一状态表、策略对比表、演练统计表和三次正式测试结果表。

## 公共写作支持

- 符号表预置坐标、方位角、误差角、定位区域、直径、接收半径和时间成本等核心符号。
- 提供定理、定义、假设、公式、图、三线表、算法、代码清单的示例及标签规范。
- 参考文献采用独立 `references.bib` 文件和 `biblatex` 管理；若本机缺少 Biber，README 同时说明如何切换到模板附带的 `thebibliography` 兼容文件。
- 附录预置程序说明、关键代码和支撑材料清单，并提醒保留三次正式测试日志原文件名。
- 所有待填写内容统一使用醒目的 `\placeholder{...}` 命令，便于全文搜索和赛前清理。

## 错误与降级处理

- 图片文件尚不存在时，使用带文件名的边框占位框，保证模板仍可编译。
- 表格中的未知实验结果使用占位命令，不填入虚假数值。
- 模板不依赖题目附件中的模拟器文件即可完成首次编译。
- README 说明中文路径可能带来的旧工具兼容问题，并提供从 `latex/` 目录编译的命令。

## 验收标准

1. `main.tex` 使用 XeLaTeX 可无交互编译成 PDF；交叉引用至少编译两遍后稳定。
2. 编译产物包含四个问题及全部公共章节，目录和引用无未定义错误。
3. 每个一级章节位于独立文件夹，且每个文件夹内只有一个 `main.tex`。
4. 问题 3 和问题 4 均含演练统计表与三次正式测试表。
5. 图片缺失时仍可编译，所有待填内容可通过搜索 `placeholder` 或“待填写”定位。
6. README 能让首次接触工程的队员完成编译、填写和清理占位内容。

## 非目标

- 不替代正式求解，不生成问题二至四的虚构数据。
- 不实现模拟器通信或搜索算法程序。
- 不承诺完全复刻尚未提供的官方论文格式文件；如后续取得官方规范，可只调整 `config/` 而不改正文目录。
