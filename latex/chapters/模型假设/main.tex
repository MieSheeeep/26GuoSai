\section{模型假设}

为使测向几何与机器狗行动过程能够统一计算，在题目给定条件之外作如下假设：

\begin{enumerate}
  \item 机器狗的位置、运动方向及接口返回值准确，通信时延相对于题设操作时间可忽略；
  \item 相邻决策点之间按直线匀速运动计算路程与耗时，转向不额外计时；
  \item 同一地点的重复测向不能消除固定示向偏差，因此不通过原地重复检测缩小误差界；
  \item 不同地点的真实测向误差均处于题设的 \([-1\degree,1\degree]\) 内；问题一按题设界处理给定示向度，问题二至四为对接接口保留两位小数的读数，采用包含舍入误差的 \(1.0051\degree\) 保守角度界；
  \item 干扰源在一次测试期间保持静止，其频道、有效接收半径和定向方向不随时间变化；
  \item 全向源在接收半径内能够被检测；定向源还须满足其发射方向的可见条件。问题三、四的发现覆盖证书以此确定性接收规则为前提；
  \item 机器狗距尚未清除的指定频道目标不超过 \(20\,\mathrm{m}\) 时，光学精确定位与清除必定成功；对已发现且未清除的频道，失败的 \texttt{/clear} 可排除该位置周围 \(20\,\mathrm{m}\) 内的源位置。
\end{enumerate}
