\section{模型假设}

在题目给定条件基础上作如下假设：

\begin{enumerate}
  \item 机器狗位置、运动方向和接口返回结果均准确，忽略通信时延；
  \item 机器狗在相邻决策点之间沿直线匀速运动，转向耗时忽略不计；
  \item 同一检测点的示向度误差固定，不通过原地重复检测降低误差；
  \item 不同地点的示向误差相互独立，且均落在题设的 \([-1\degree,1\degree]\) 内；
  \item 干扰源在一次测试中保持静止，频道、有效接收半径与定向方向均不变化；
  \item 当距离不超过 \(20\,\mathrm{m}\) 时，光学定位和清除操作的成功条件完全按题目规定执行。
\end{enumerate}
