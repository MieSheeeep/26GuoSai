\section{模型评价与推广}

\subsection{模型优点}
\begin{enumerate}
  \item 几何约束直接对应测向误差边界，定位区域具有清晰的物理含义；
  \item 搜索、测向、复测与清除统一计入时间成本，便于在模拟器中复现；
  \item 状态机结构可同时维护多个频道的置信状态，适合数量未知的干扰源；
  \item 问题四通过多方位观测减轻定向辐射导致的单点漏检。
\end{enumerate}

\subsection{模型推广}
模型可扩展到移动干扰源、多机器狗协同和存在障碍物的环境。可将静态可行域替换为时变概率图，并使用任务分配与滚动时域优化协调多台设备。
