\section{模型检验、评价与推广}

\subsection{模型检验结果汇总}
问题一的半平面交结果由真实位置回代和顶点对枚举交叉复核，问题二用同一首次示向比较两组执行参数。问题三的 $3500$ 个随机样例和问题四的 $2100$ 个随机样例均完整清除；改变空间分布、源类型和发射朝向后，每类 $500$ 次检验仍未出现未完成清除的样例，Wilson $95\%$ 置信下界为 $99.24\%$。三、四问各三次正式测试记录了接口环境中的清除数量、平均定位清除时间和程序运行时间。随机实验用于评价预设分布下的稳定性，正式测试用于核对接口执行，两类证据不相互替代。

\subsection{模型优点}
四问从单次测向推进到多源闭环搜索：先建立位置约束，再讨论下一检测点，最后同时处理已发现源的清除与未知频道的发现。各阶段可以核验的内容如下：
\begin{enumerate}
  \item 本模型在问题一中把示向度误差写成半平面交，使定位区域的每条边都能追溯到具体观测；直径与圆覆盖分开检验，避免把二者混同；
  \item 本模型在问题二中以位置可行集投影和双侧偏移给出明确的候选区域，前移比例与侧移距离分别控制纵向行程和交会几何，并与问题三、四的首次复测规则一致；
  \item 本模型在问题三中按频道维护位置可行集，并检查已完成巡检点的接收圆是否覆盖目标区域，以判断未知频道是否得到全域排查；
  \item 本模型在问题四中不以单点无信号排除定向源，而是根据多方位观测判断哪些区域与全部无信号结果矛盾。
\end{enumerate}

\subsection{模型局限与适用边界}
当前模型与证据仍有以下限制：
\begin{enumerate}
  \item 本模型在问题二中只用一个事后设定的源位置检验算例；双侧候选构造不是全域最优性证明，实际接收与定位效果仍须依据后续观测及三、四问测试评价；
  \item 问题三、四的全域覆盖条件以及问题四的有限网格清除步骤都建立在动作能够全部执行的前提下；若动作数或实际运行时间先耗尽，不能据此声称已清除全部干扰源；
  \item 本模型的随机实验环境按题设物理规则自行构造，其源位置、类型和朝向分布不代表正式模拟器的隐藏生成机制；表中成功比例只刻画本文预设场景；
  \item 本模型在问题三、四中各只有三次正式测试，足以核对程序能够在接口环境中完成任务，但不足以据此估计真实失败概率或比较小幅时间差异；
  \item 本模型的虚拟时间未计入通信和转向耗时，若用于实体设备，应先测量这些开销并重新标定决策参数。
\end{enumerate}

\subsection{模型推广}
若干扰源可能移动，静态位置可行集需随新观测实时更新；若场地存在障碍，第二检测点的直线移动距离应改为可通行路径长度。多机器狗协同时，还需分配巡检区域与目标，避免重复测向和路径冲突。扩展时仍可沿用“记录观测、更新位置可行集、比较下一行动”的闭环；能否保证接收，则须按全向或定向场景分别判断。
